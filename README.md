Entry for the [make.fun](https://make.fun/c/u-tuan-muda-one-word-for-your-wi-fi-a1b4fd72) bounty **One Word for Your Wi-Fi**: a single word describing home Wi-Fi, judged pairwise on how funny and how true it is.

## How it works

`main.ts` (Node 22, no network, fully deterministic) writes one word of at most 20 characters to `/output/entry.txt`:

> situationship

Full bars at 3 a.m., gone the moment the meeting starts, never fully committed.

Run it with:

```sh
node main.ts
```

The output directory can be overridden with the `OUTPUT_DIR` environment variable.
